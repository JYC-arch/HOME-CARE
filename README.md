# 各國居家護理制度比較：分組活動設計

**學生互動填寫頁：[開啟活動](https://jyc-arch.github.io/HOME-CARE/)**

選擇組別後，即可在線填寫、查看即時預覽、儲存本機草稿，並下載 JSON 成果檔、文字紀錄或列印 PDF。每組由一台裝置填寫即可。草稿僅保存在目前瀏覽器，不會自動上傳；請下載後依教師指定管道繳交。也可匯入先前下載的草稿或成果繼續修改。

## 活動目標

1. 說明不同國家居家護理與長期照顧制度的財源、評估、服務提供與特色。
2. 將各國制度套用於同一個案，分析照護流程的差異。
3. 比較台灣與他國做法，提出可借鏡之處及台灣值得保留的做法，並說明理由。

## 國家分配與查詢方向

| 組別 | 國家 | 查詢方向 |
|---|---|---|
| 1 | 日本 | 介護保險（2000年起）、訪問看護站、地域包括照護體系；亞洲成熟長照制度，適合比較需求評估、個案管理與社區整合 |
| 2 | 韓國 | 老人長期療養保險（2008年起），亞洲另一個以社會保險辦理長照的國家 |
| 3 | 德國 | 長照保險（1995年起），可選擇現金給付或實物服務，對照台灣沒有長照保險 |
| 4 | 英國（英格蘭） | 區分 NHS 提供的醫療與社區護理（含虛擬病房／Hospital at Home），以及地方政府負責的社會照顧 |
| 5 | 美國 | 比較 Medicare 的居家專業醫療給付與長期生活照顧的保障差異 |
| 6 | 丹麥 | 稅收支應、由地方政府提供，以復能（reablement）為核心，對照台灣長照的居家復能 |
| 7 | 澳洲 | Support at Home 於2025年11月1日取代 Home Care Packages 與短期復能照護方案；CHSP 預計2027年7月1日以後才併入 |

## 共同個案

> 林奶奶，82歲，獨居。中風後左側肢體無力，需他人協助移位。薦骨有第二級壓力性損傷，留置導尿管。女兒白天上班，只能晚上探視。

各組回答：**「如果林奶奶住在這個國家，她會怎麼取得居家護理與照顧服務？」**

---

## 討論項目（依照護流程）

| 步驟 | 學生要回答的問題 | 範圍限制 |
|---|---|---|
| 1. 誰來評估 | 林奶奶去哪裡申請？由誰評估？用什麼方式評估？ | 找出申請入口與評估方式即可，不要求找到對應巴氏量表或 CMS 的工具 |
| 2. 誰來照護 | 壓力性損傷與導尿管由誰處理？護理師與其他人員怎麼分工？ | 以護理師角色與團隊分工為主；「護理師能否獨立開業」可延伸查詢 |
| 3. 誰付錢 | 經費來源是社會保險、稅收還是自費？舉一項服務說明自付多少 | 只需舉一項代表性服務，不必查完整費率 |
| 4. 特色服務 | 選一項深入介紹：在宅急症、復能、遠距照護或安寧居家 | 須附一項有年份的推行現況或執行困難 |
| 5. 與台灣比較 | 林奶奶在台灣會怎麼走？提出一項台灣可借鏡之處，以及一項台灣值得保留的做法 | 均須說明理由；資料不足時明確指出，不必勉強下結論 |

報告時，至少一半時間用於第5項。
